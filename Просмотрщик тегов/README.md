# Просмотрщик тегов ПЛК — exe-версия

## Запуск

Просто запустите `PlcTagViewer.exe`. Ничего устанавливать не нужно:
ни Python, ни .NET, ни веб-сервер — всё встроено в один файл (76 МБ).

## Как это работает

1. При запуске exe поднимает встроенный веб-сервер на `127.0.0.1`
   (случайный свободный порт, доступ только с этого компьютера).
2. Если в системе есть **Edge WebView2 Runtime** (предустановлен в Windows 10/11
   с Edge) — приложение открывается в собственном окне, без браузера.
3. Если WebView2 нет — автоматически открывается браузер по умолчанию,
   а exe показывает маленькое окно-заглушку («Открыть снова» / «Выход»).

Закрытие окна exe завершает сервер.

Файлы приложения зашиты внутрь exe как ресурсы — папки `wwwroot` рядом
не требуется, exe можно переносить и запускать откуда угодно.

## Возможности приложения

Полная версия веб-приложения: загрузка файлов CODESYS (Symbol XML,
PLCopen / Application Composer, текстовый экспорт ST) и SYSMAC Studio
(TXT/CSV) перетаскиванием или через диалог, дерево тегов с иконками
и счётчиками элементов, комментарии на всех языках, поиск и фильтр
по типу, копирование имени/пути/комментария, клавиатурная навигация,
вкладки с сохранением при перезапуске и выносом в отдельное окно,
обновление файла кнопкой с подсветкой новых тегов, тёмная тема.

Примечание: кнопка «Обновить» перечитывает файл без повторного выбора
только в Chromium-браузерах (внутреннее окно WebView2 — это Chromium,
так что в exe-режиме всё работает).

Для быстрого просмотра без своих файлов добавьте к адресу `?demo=1`
(например `http://127.0.0.1:ПОРТ/?demo=1`, порт виден в адресной строке
открывшегося окна) — загрузятся встроенные образцы CODESYS и SYSMAC.

## Исходники лаунчера

Папка `Исходники лаунчера` — проект .NET 8 (WinForms + HttpListener +
WebView2). Сборка:

```bat
dotnet publish -c Release
```

Само веб-приложение (Blazor) лежит в архиве «Просмотрщик тегов ПЛК (Blazor).zip».
После его пересборки замените содержимое папки `wwwroot` лаунчера
файлами из `publish/wwwroot` (без `.br`, `.gz`, `.pdb`) и соберите заново.
