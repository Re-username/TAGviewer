# Просмотрщик тегов ПЛК (Blazor WebAssembly)

Веб-приложение для просмотра экспортированных переменных CODESYS и SYSMAC Studio
в виде раскрывающегося дерева с комментариями. Работает полностью в браузере,
без сервера и установки.

## Запуск

Приложению нужен любой статический HTTP-сервер (из-за ограничений WASM
по `file://` оно не откроется).

Варианты:

```bat
REM Windows + Python
cd Приложение
python -m http.server 8080
```

```bat
REM Windows + Node.js
npx serve Приложение
```

или скопируйте папку `Приложение` на любой веб-сервер (IIS, nginx, Apache).
После запуска откройте в браузере `http://localhost:8080/`.

Рекомендуемый браузер — Chrome / Edge (Chromium): только там доступно
перечитывание файлов кнопкой «Обновить» (File System Access API).
В Firefox и Safari обновление выполняется повторным выбором файла.

Быстрый просмотр без своих файлов: добавьте к адресу `?demo=1` —
загрузятся встроенные образцы CODESYS и SYSMAC.

## Возможности

- Загрузка файлов перетаскиванием или через диалог:
  - CODESYS: Symbol Configuration (.xml), PLCopen XML (Application Composer),
    текстовый экспорт деклараций (ST);
  - SYSMAC Studio: таблицы TXT/CSV из .smc2 (разделитель и колонки
    определяются автоматически, кодировки UTF-8 и Windows-1251).
- Дерево тегов: отступы, иконки (структура / массив / элемент массива /
  переменная), количество элементов у структур и массивов, комментарии
  на всех языках (Comment_ru, Comment_en и т. д. собираются вместе).
- Обновление: кнопка «Обновить» перечитывает файл; изменённый на диске файл
  подсвечивается автоматически (проверка каждые 3 с); новые теги помечаются
  значком «new»; в статус-баре — дата/время обновления и общее число тегов.
- Поиск по имени, пути и комментарию; фильтр по типу данных
  (BOOL, целые, REAL, STRING, TIME/DATE, структуры, массивы).
- Копирование в буфер: имя, полный путь (например `GVL.Motor1.Speed`),
  комментарий. Ctrl+C копирует путь выбранного тега.
- Клавиатурная навигация: стрелки — по дереву, Enter — раскрыть/открыть
  во вкладке, Ctrl+Enter — вкладка, Ctrl+F — поиск, Ctrl+O — открыть файл,
  F5 — обновить, F12 — тема.
- Вкладки: двойной клик по узлу открывает его в отдельной вкладке;
  вкладки и загруженные файлы сохраняются при перезагрузке страницы;
  кнопка ⧉ выносит вкладку в отдельное окно (синхронизация каждые 2 с).
- Тёмная и светлая темы.

## Исходники

Папка `Исходники` — проект .NET 8 (Blazor WebAssembly).
Сборка: `dotnet publish -c Release` (нужен .NET SDK 8+),
результат — в `bin/Release/net8.0/publish/wwwroot`.
